# RoomLab · 特工行动 v10.1

双人合作网页原型：A 在现场操作，B 在后方指挥或接力。通过语音交换不对称信息，限时潜入、取回档案并一起撤离。

[线上试玩](https://loran-f.github.io/roomlab/roomlab.html) · [密室选择](https://loran-f.github.io/roomlab/roomlab.html?m=dungeon)

## 开始游戏

主界面 → 选择密室 → A 创建房间，B 输入四位房间码加入。两名玩家各用一台设备，语音使用自己的聊天软件。房主决定密室，加入者自动同步选择与地图。

选择页包含 13 张封面，左右滑动、两侧箭头或键盘方向键切换，首尾循环，刷新保留当前选择。标题来自封面文件名。`ROOM_CATALOG` 配置主题、推荐语、评分、时长、难度和标签；这些为原型展示数据，首张 8.1 分 / 5 分钟沿用参考图，其他密室暂无评分。各封面目前共用特工爬塔规则。

## 卷轴地图 · v10.1

爬塔界面沿用主界面与选择密室页的紫色背景、粗描边和暖黄色按钮风格。地图改为奶油色卷轴，进入时展开约 1 秒；系统开启减少动态效果时直接展示完整地图。

11 个普通玩法、Boss、入口和安全屋共 14 个独立扁平 SVG 图标。地图用实线、虚线、锁和完成标记区分路线状态，A/B 位置始终以字母标明。双人同步不会重复播放展开动画，节点保留 3 秒集合倒计时。

## 密室路线

五层分支地图：潜入入口 → 三层事件 → 最终对峙。双方只能沿连线移动，同点停留 3 秒进入行动，离开会打断读条。

- 共用 5 格生命；事件或 Boss 失败扣 1 格，并退回前一已完成节点，可以重试。
- 成功解锁下一层，选择一条分支后同层其他分支锁定。
- 安全屋恢复 1 格生命，上限 5 格。
- Boss 成功后整局胜利；生命归零整局失败。整局结束由房主开启下一局，B 自动同步。
- 双方可从玩法返回地图。断线时新实时玩法停止输入与判定，并提示重新建房。

事件池为 11 个玩法，Boss 只在最终节点出现。地图保留原来的拓扑与推进规则，视觉改为特工路线图，节点显示行动名称。

## A：最终对峙（新增 Boss）

[A 创建](https://loran-f.github.io/roomlab/roomlab.html?m=boss&role=A) · [B 加入](https://loran-f.github.io/roomlab/roomlab.html?m=boss&role=B)

限时 100 秒，共用 7 格装甲；两端准备就绪后显示 3 秒倒计时。装甲只属于本次 Boss 战斗，耗尽时密室生命扣 1。

| 阶段 | 操作与目标 | 互坑点 |
|---|---|---|
| 拦截警报 | 按 A / B / AB 提示，在判定时按住对应护盾，成功 12 次 | AB 必须一起挡；一直按会过热，损失装甲并冷却 1.6 秒 |
| 接力破解 | 判定时仅指定角色按住，A/B 交替，成功 10 次 | 抢按、两人同按或漏接会断链并损失装甲 |
| 同步撤离 | 绿灯窗口内，两人各点一次，间隔不超过 0.38 秒，成功 5 次 | 提前按或不同步损失装甲，每轮要松开再按 |

手机使用下方按钮，键盘使用空格 / Enter。阶段之间有 2 秒提示时间。房主计算判定，B 上报输入，胜负和提示同步。独立试玩“再来一局”需要双方确认。

## B：特工主题与玩法对照

主题阶段只改名称、视觉和叙事；除 A/C/D 所列新增或调整项外，原有数值和操作规则保持不变。

| 原玩法 | 特工行动 | A / B 分工 | 通关与时限 |
|---|---|---|---|
| 迷宫走线 | 通风潜行 `maze` | A 盲走，B 全图指挥 | 终点；120 秒，碰墙 -5 秒、陷阱 -8 秒 |
| 转盘对接 | 频段校准 `dial` | A 报卡号转针，B 查表 | 对齐 ±1；90 秒，锁错 -3 秒 |
| 剪线排雷 | 警报拆线 `wires` | A 报色剪线，B 三步规则 | 连剪三根；90 秒，剪错即失败 |
| 对暗号 | 接头暗号 `code` | A 描述符号，B 密码本 | 四位密码；120 秒，输错 -3 秒 |
| 记忆暗格 | 档案窃取 `vault` | A 扫描，B 按位序记录 | 5—7 位；120 秒，详见 C |
| 锅炉校准 | 动力稳压 `pressure` | A 调压力，B 看区间与开阀 | 三轮；90 秒，详见 D |
| 物资空投 | 情报空投 `catch` | A 左移，B 右移 | 接够 20；60 秒 |
| 双人护盾 | 双人屏障 `shield` | 各控制一半屏障 | 能量 20；60 秒，耐久 3 |
| 双人抬梁 | 破障搬运 `beam` | A 抬左，B 抬右 | 收集 20；60 秒，滑落 5 次失败 |
| 双人节拍 | 信号节拍 `beat` | 蓝 A / 橙 B / 紫共同 | 30 分；60 秒，8 次失误机会 |
| 双人架桥 | 撤离架桥 `bridge` | A 左移，B 右移 | 运送 5；60 秒，甩落 5 次失败 |

独立试玩的迷宫、转盘、剪线、暗号沿用 A 现场与 B 手册的口头配合；档案独立试玩由 A 手动确认 B 报回结果。进入密室后使用已有房间进行判定和结算同步。其余实时玩法通过建房 / 加入联机。

## C：档案窃取难度曲线

| 场景 | 位数 | 每位亮起时间 |
|---|---|---|
| 独立试玩、第一事件层 | 5 | 1 秒 |
| 第二事件层 | 6 | 0.8 秒 |
| 第三事件层 | 7 | 0.6 秒 |

密码按随机位序逐个亮起，位与位之间留 0.25 秒。A 报“第几位、什么数字”，B 点击对应格子再按数字。错误提交扣 3 秒并清空 B 记录；A 可花 3 秒重新扫描同一密码。房主只同步位数、速度与层数，不发送答案。退出时取消扫描定时器和提交处理。

## D：动力稳压回归

- A 看到压力，按住加压 / 减压（也支持键盘 ↑ / ↓）；B 看不到压力，只能听 A 报数。
- B 看到宽度 20 的安全区间、下一段目标与切换倒计时，A 不收到这些字段。
- 区间每 6 秒改变移动目标，每秒最多移动 4 个单位；压力有惯性和波动。
- B 确认读数在区间内后按住校准阀，每轮累计稳定 4 秒，共三轮。无效状态会缓慢流失本轮进度。
- 区间外持续开阀 1.25 秒或阀温到 100% 损失 1 格设备耐久，并冷却 1.5 秒。松手散热。
- 设备耐久 3，压力撞到 0 / 100 或 90 秒用尽均失败；密室生命按统一规则只扣 1 格。

Boss 和动力稳压使用统一的房主实时会话框架，约 15Hz 广播，650ms 未刷新输入则自动松手。输入包含局号和递增序号，过期输入不参与新局。

## 本地运行

在 `prototype` 目录执行：

```sh
npm install
node start.js
```

电脑访问 `http://127.0.0.1:8080/roomlab.html?m=dungeon`；手机连接同一 Wi-Fi，使用电脑局域网 IP 替换 `127.0.0.1`。启动器提供静态页面（8080）与 PeerJS 信令（9000）。

本地 IP / localhost 自动使用本机信令；公网域名使用 PeerJS 公共云。可用 `?peer=主机&peerPort=端口&peerSecure=0或1` 显式指定。公共信令的可达性受玩家所在地网络影响。

## 文件与协议

- `roomlab.html`：界面、地图、全部玩法和实时引擎。
- `assets/rooms/`：13 张封面；`pic.png`：主界面角色；`peerjs.min.js`：联机库。
- `PLAYGROUNDS` 注册玩法，`EV_POOL_NET` 注册普通事件，Boss 单独进入。
- `dg` 快照包含 `roomId` 和节点 `mode`；`enter` 对档案附带 `vault:{digits,flashMs,layer}`。
- `rtReady` 确认就绪；`rtInput` 上报带局号、序号的输入；`rtState` 同步角色画面、倒计时和结果。
- `vaultSubmit` 由房主校验，`vaultResult` 同步成败；`dgEnd` 统一处理密室推进与胜负。

## 发布

按用户指令发布到 `loran-F/roomlab` 的 `main`，通过 GitHub REST Contents API 先读 SHA 再 PUT，不用 `git push`。先上传封面与依赖，最后上传 `roomlab.html`，并验证 Pages 的实际文件。

`tools/deploy_github.py` 默认只列出发布清单；添加 `--publish` 执行。凭据从 `GH_TOKEN` / `GITHUB_TOKEN` 或项目外一层的 `.github-token` 读取，不写入仓库。不会上传调试截图、临时脚本、node_modules 或内部交接原文。

验证记录见 [VALIDATION.md](VALIDATION.md)，版本更新见 [CHANGELOG.md](CHANGELOG.md)。
