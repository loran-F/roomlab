# RoomLab · 主题密室 v13

双人合作网页游戏：两个人各用一台设备，通过语音交换线索，一起解谜、操作机关和探索密室。

[线上试玩](https://loran-f.github.io/roomlab/roomlab.html?v=13) · [选择密室](https://loran-f.github.io/roomlab/roomlab.html?m=dungeon&v=13)

## 开始游戏

主界面 → 选择密室 → A 创建房间，B 输入四位房间码加入。两人使用自己的语音聊天软件交流。房主选择密室并生成地图，加入者同步同一张地图。

也可以从玩法大厅单独体验。目前有 **17 间密室、17 种不同的主玩法**；加上信号节拍和最终对峙，大厅共 **19 个玩法入口**。

## 这次更新

- **密码推条**：自己推动密码条，只能看见对方正面的数字。互相报方向，让数字完整进入窗口并确认；先学左右推，之后加入上下推。
- **默数开灯**：A 默数约 10 秒再拉灯，时机正确时给 B 约 10 秒全景照明，拉错则只剩局部视野。B 移动探索，找到并走近灯的总开关。下一次拉灯需要重新掌握节奏。
- 每间密室有固定主玩法及相应的场景、道具或线索主题，详细对应见 [密室分配](ROOM_PROGRESSION.md)。例如接小花盆、鱼箱搬运、旧照片、山径、双胞胎影子、录音室和宫廷疑案。
- 全玩法按钮整理为单一底色和直接文字，清除内层蓝橙色块。档案基础关恢复固定四格逐一显示；影子替身基础关使用一个按钮、一扇门、一把钥匙。
- 卷轴地图按规则随机生成节点数量、位置和路线，使用扁平玩法图标；进入时播放展开动画，系统减少动态效果时直接展开。

## 地图和解锁

所有密室都可以选。首挑战层练习本室主玩法，后段有必经的进阶挑战。中间从本室主玩法、主题相关且已解锁的辅助玩法以及基础信号节拍中抽取。

两人沿连线移动，在同一节点集合后进入玩法。失败会扣共用生命，退出不扣生命；重试不会重抽地图。地图可以上下滚动，并使用「回到我」定位。

**完整通关一间密室，才会解锁其主玩法作为之后的辅助玩法。** 普通节点胜利不解锁，失败和退出也不解锁。A/B 各自保存进度，刷新保留；进度按浏览器和网站来源保存，没有账号云同步。主机用自己的解锁记录生成整局路线。

除三间机械主题密室使用最终对峙外，其余密室以自己的主玩法作为终章。主玩法与地图协议见 [适配说明](ROOM_GAME_ADAPTERS.md)，路线规则见 [随机地图说明](DUNGEON_ROUTES.md)。

## 本地运行

在 `prototype` 目录执行：

```sh
npm install
node start.js
```

电脑打开 `http://127.0.0.1:8080/roomlab.html?v=13`。两台手机连接同一 Wi-Fi，将地址中的 `127.0.0.1` 换成电脑的局域网 IP。启动器提供静态页面（8080）和 PeerJS 信令（9000）。

localhost / 局域网地址使用本机信令，公网域名使用 PeerJS 公共云。可用 `?peer=主机&peerPort=端口&peerSecure=0或1` 指定信令服务器。

## 文件与验证

`roomlab.html` 是入口，玩法由独立 JS/CSS 模块扩展；`room-progression.js` 管理匹配和解锁，`dungeon-routes.js` 生成地图。`assets/rooms/` 保存封面，`assets/map-icons/` 保存节点图标。

本地使用双浏览器页面、实际 PeerJS/WebRTC 连接和手机视口验证。完整测试范围、注入场景与限制见 [VALIDATION.md](VALIDATION.md)。评分、时长和标签为原型配置；跨地域网络和真人趣味性仍需实际体验。
